# HNRNPD_multiomics

Main analysis scripts for the HNRNPD multiomics study in EndoC-βH1 and RPE cells: isoform-specific RNA binding, total-RNA abundance and ribosome-associated RNA abundance.

## Analysis folders

| Dataset | Workflow | Data |
|---|---|---|
| [iCLIP-seq](scripts/iclip/) | STAR → UMI deduplication → PureCLIP → BindingSiteFinder → GO enrichment | [GSE350757](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE350757) |
| [Long-read RNA-seq](scripts/long_read_rnaseq/) | Read preparation → minimap2 → IsoQuant → DESeq2 → GO/KEGG enrichment | [GSE350755](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE350755) |
| [TRAP-seq](scripts/trap_seq/) | Reference preparation → Bowtie2 → STAR → Salmon → DESeq2 → GO/KEGG enrichment | [GSE350756](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE350756) |

The three datasets are linked under GEO SuperSeries [GSE350758](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE350758). The repository contains 18 dataset-analysis scripts and one reusable enrichment script for integrated target-gene lists.

## Using the scripts

Download the repository and follow the README in the relevant dataset folder. Edit the input/output paths and sample selectors at the top of each script, activate its required software, then run Bash files with `bash filename.sh` or R files with `Rscript filename.R`.

`/path/to/...` values are user-configurable locations. Use a consistent absolute output root within each workflow. Scripts retain the supplied analysis parameters and check required inputs; existing outputs are protected against overwriting.

GEO provides sequencing data, processed count matrices and sample metadata. The iCLIP workflow starts from post-Ultraplex FASTQs and uses deposited BigWigs for binding-site definition. RNA-seq DESeq2 scripts start directly from the processed GEO count matrices, already restricted to protein-coding genes and lncRNAs. Dataset READMEs specify reference downloads and software dependencies. The long-read junction reference is included; the TRAP contaminant reference is generated by its preparation script.

## Enrichment of integrated target lists

[`scripts/integrated_functional_enrichment.R`](scripts/integrated_functional_enrichment.R) runs the original GO BP/MF/CC and KEGG analysis for any selected list. Set `ROOT`, `CELL`, `GENE_SET`, `GENE_FILE` and `SHEET`, then run `Rscript scripts/integrated_functional_enrichment.R`. The Excel input needs a `geneName` column of human gene symbols. Requires clusterProfiler, org.Hs.eg.db and openxlsx; KEGG needs internet access.

Lists analysed were:

- **EndoC:** p42; p45; shared p40/p42/p45; shared p42/p45.
- **RPE:** p37; p40; p42; p45; shared p37/p40; shared p37/p40/p42; shared p37/p42; shared p40/p42/p45; shared p40/p45; shared p42/p45.

These labels identify the supplied lists; the script does not recreate or alter their selection. It retains the original database background, BH adjustment and enrichment settings. Results under `ROOT/CELL/GENE_SET/` include all returned terms, nominal p < 0.05 exploratory terms and BH-adjusted p < 0.05 terms in separate sheets, together with input mapping, settings and session information. Database updates may change results.

## Interpretation

`SCR`, `EX2`, `EX7` and `EX2EX7` denote scrambled control, exon 2 exclusion, exon 7 exclusion and combined exclusion. Comparisons are performed within cell type. Exploratory nominal-p results are labelled separately from BH-adjusted results. Enrichment input thresholds are configurable and should match the analysis being reproduced. TRAP-seq measures ribosome-associated RNA abundance; transcript-level differential abundance does not by itself establish differential transcript usage.
